Accesibilidad

Última actualización: 27 de septiembre de 2026

Esta web intenta cumplir las pautas WCAG 2.1 nivel AA, para que la pueda usar cualquier persona.

Qué se ha hecho

  • Contraste: el texto y los botones tienen un contraste mínimo de 4,5:1 con su fondo (el texto grande, de 3:1).
  • Teclado: todo se puede usar con el teclado. Tab recorre enlaces y botones, cada elemento enfocado se marca con un borde visible y al principio hay un enlace para saltar al contenido. Las capturas se abren con Intro y se cierran con Esc o con el botón «Cerrar».
  • Texto alternativo: todas las imágenes tienen una descripción, y los iconos decorativos están ocultos para los lectores de pantalla.
  • Etiquetas claras: los enlaces y botones dicen qué hacen (por ejemplo, «Descargar la versión 1.5.52» en lugar de «aquí»).
  • Estructura: la página usa títulos ordenados y zonas marcadas (cabecera, contenido y pie) para moverse con lectores de pantalla.
  • Movimiento: si tu sistema tiene activada la opción de reducir el movimiento, se quitan las animaciones.
  • Sin JavaScript: todo el contenido se ve igual y el botón de descarga funciona.
  • Tamaño: la web se adapta al móvil y se puede ampliar hasta el 200 % sin perder contenido.

Limitaciones conocidas

  • Las capturas del juego son imágenes: su descripción resume lo que se ve, no cada detalle.
  • El historial de versiones y las novedades vienen de GitHub y se muestran tal como se publicaron.
  • El juego en sí, fuera de la web, todavía no tiene todas las opciones de accesibilidad (por ejemplo, subtítulos de los sonidos).

¿Encuentras un problema?

Si algo de la web no se puede usar bien con tu forma de navegar, avisa en las incidencias del proyecto y se intentará arreglar lo antes posible.
